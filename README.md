# The Chinese Foreign Policy Elite Atlas

A single-page, self-contained reference on China's foreign-policy elite — the Ministry of
Foreign Affairs and adjacent institutions (CPC International Department, MOFCOM, MND/PLA, Taiwan
Affairs Office, CIDCA), plus a growing "Track Two" layer of influential academics and think-tank
figures. Includes a rank ladder, a world map of postings, a network view, an issue-portfolio map,
an origins map, a "who's next" promotion-watch list, an organisation tree, and a "Briefing" tool
that builds a sourced shortlist of who to talk to for a given country/scenario, including recent
MFA podium excerpts.

**Live site:** https://jamiegjo.github.io/china-elite-atlas/

This repo holds only the finished, built page (`index.html`) — a static file with every data
layer already embedded, no build step and no server required. It is generated from a private
research pipeline; this repo is not where the pipeline itself lives.

## Updating

The published page is rebuilt from the source project and copied here as `index.html`, then
committed and pushed — GitHub Pages serves whatever is on `main`, no CI build step needed since
the file is already complete.

## Sourcing and disclosure

Every claim in the atlas is meant to carry its own source; a "method" panel on each tab explains
how that section was built and what its known gaps are. Treat it as a working reference, not a
finished, error-free record — corrections are welcome via GitHub issues.
